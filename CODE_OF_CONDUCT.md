# Código de Conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: trata a todo el mundo con respeto, sin acoso ni discriminación de ningún tipo; critica ideas, no personas; y acepta con buena fe las correcciones.

Para reportar un comportamiento inaceptable, contacta con quien mantiene el proyecto a través de [GitHub](https://github.com/SamonsLol). Todos los reportes se tratarán de forma confidencial.
